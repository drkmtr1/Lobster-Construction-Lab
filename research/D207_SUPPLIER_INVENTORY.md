# D207 independent-supplier inventory and exact domains

Read this with the [strategic assessment](D207_INDEPENDENT_SUPPLIER_ARCHITECTURE.md). Indices in the ledgers route to the pinned mathematical arguments. This inventory groups developments by distinct supplied object or interface, including the important conditional consumers that a coverage argument might mistake for suppliers. It does not replace the proof or historical disposition of any grouped subcase.

## Conventions

A section is the actual spine vertex's ordered list of branch quotas. An entry 0 means an actual direct leaf, and an empty list means that the spine vertex has no off-spine children. A complete graceful object with (m) edges uses labels ([0,m]) and weights ([1,m]) unless a source temporarily uses a translated alphabet. For an unfinished target, (R,Q) are the remaining vertex labels and differences in the target alphabet. All parameters and labels are exact integers. Every stated port is an actual vertex, with optional reflection only where the result allows it. Permuting sibling identities as a transport between declared indexed roles does not move leaves between parents.

A **standalone supplier** constructs an admitted original or local operand from its parameters. An **extension supplier** has a supplied state and constructs fresh roles and allocations independently of a successful final labeling. An **extractor** constructs only after compatibility data pass a theorem. A **formulation** encodes the remaining existential question. The table lists proved membership in each named domain, including exact model tests where available. A sufficient row gives no converse outside its stated model.
