# Codex return — audit OpenChamber changes first

Before starting any new research, read `AGENTS.md`, `STATE.md`, `docs/OPENCHAMBER_HANDOFF.md`, latest `handoffs/OC-*.md`, relevant findings/failures/proof obligations, and the **actual** code and evidence.

Locate the last accepted review commit, or use `lcl-v0.1.0-baseline` if none later has been accepted. Review *all* intervening committed changes and any uncommitted/untracked material. Do not infer no changes from a clean working tree. Check altered source/configuration/checker identities, topology fidelity, physical ports and branch identities, integer-range and distinct-difference mathematics, restricted-vs-unrestricted claims, alpha assumptions, formula domains, solver pruning/symmetry/completeness, independent verifier behavior, experiment provenance and exact count claims. Re-run the relevant bounded checks and any independent small oracle comparisons justified by risk. Read primary arguments rather than depending on OpenChamber summaries.

Provide an explicit **ACCEPT / REVISE / REJECT** finding for each consequential claim and change, with evidence and precise limitations. Distinguish finite witnesses, restricted exhaustive negatives, incomplete runs, independently supplied parameterized constructions, conditional consumer results and historical novelty. Preserve all baselines and failures. Correct or update `research/FINDINGS.md`, `research/FAILED_HYPOTHESES.md`, `research/PROOF_OBLIGATIONS.md`, `research/DECISIONS.md` and `STATE.md` only as their scope requires. Record the accepted commit (if any) and one next action. Stop without automatically launching a new research campaign. GitHub synchronization for this project is authorized under `docs/REPOSITORY_CONTINUITY.md`; do not modify upstream repositories or install paid components without separate authorization.
