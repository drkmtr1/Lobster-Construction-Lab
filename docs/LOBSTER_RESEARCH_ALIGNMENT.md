## One proposed bridge for Director consideration

**Prove or delimit a pinned two-host shell lift that supplies the D157 exceptional initializer.** The live two-reflector direction already addresses the conditional consumer. The literature strengthens the independent-supply side, where another allocation engine on a given exterior would leave the shell/port problem untouched. Matching contraction gives an independent shell labeling, ordinary transfer preserves or redistributes a supplied packet, and a shared label-to-difference map can simplify a proven batch. The shell lift is the single proposed bridge because it asks which of these inputs can actually produce a new named state rather than merely describing how to consume one.

**Declare the first family precisely.** Fix an actual path `v₀,…,v_(2L−1)`, `L≥4`, and actual off-path centers `a,b` attached to `v_(2j),v_(2j+1)`, with `1≤j≤L−2`. Each center has one deterministically retained actual terminal and a prescribed list of `r_a,r_b≥0` surplus terminals, with `t=r_a+r_b` positive and odd. All other incidences are on the path. The path stays longest. Any one-terminal route adds two edges at a site at least two edges from either end, and a route between sites off the path uses at most five edges. The shell keeps the retained terminals and pairs both center-terminal edges and consecutive path vertices. Put `e=2L+3` for shell edges and `m=e+t`. The named frontier is `v₀`, fixed before any labeling. Contract the indicated matching and use an independently constructed graceful labeling of the caterpillar contree pinned at zero on the pair containing `v₀`. Obtain shell labels `f` with `f(v₀)=0` by the perfect lift in the register. Only a contree pin with its own proof is admissible.

**Test one exact embedding.** For an integer shell cut `b₀∈[1,e]`, keep `f<b₀` and add t to every `f≥b₀`. At the target cut `C=(m−2)/2` require `b₀≤C≤b₀+t`, so old memberships persist. If `W_×` is the actual shell crossing set at `b₀` and `W₀=[1,e]∖W_×`, the unused vertex interval is `R=[b₀,b₀+t−1]` and the unused differences are

```text
D = [1,m] ∖ (W₀ ∪ (W_× + t)).
```

Require the two used weight sets to be disjoint, with `W₀⊆[1,C]` and `W_×+t⊆[C+1,m]`. For every surplus terminal at its own host take the host-tagged candidate `(x,|x−f_new(host)|)` within R and D, retaining it only if its cut crossing agrees with the required weight band. Seek an explicit parameter rule for the contree labeling and shell cut that makes the two-host quota projection contain `r_a`, preferably by a common batch map or the R226 reflected-pair decomposition. An exact matching formulation with the desired cut assumed as an oracle would leave the main supply obligation open.

**Expected conclusion and stopping rule.** Prove a nonempty parameterized domain in `(L,j,r_a,r_b)` with a constructive cut and palette split, or give a symbolic obstruction that identifies precisely which parameter range or requirement defeats this shell-lift template. On success, assign every remaining label to its prescribed actual terminal at its host, with exact crossing/noncrossing spectra `[C+1,m]` and `[1,C]`. Return the full named `S₋₁` initializer with actual port `v₀`, and its maximum-polarity complement at cut `m−C+1`. Show that each later admitted D157 block can consume it with its own phase, physical spine and size premise `m≥2K`. A proof of gracefulness without the cutoff or exact frontier is insufficient. A rejection would have the scope of the declared two-band embedding and pinned strong shell lift.

**Controls and necessary checks.** Use the LH-E30 perfect-shell construction for the source, the LH-E06 counterexample to forbid upgrading a matching pin to arbitrary chosen endpoints, and LH-E29's one-map packing as a positive model for simultaneous palettes. Use the R226 N224 fractional failure to test quota integrality. Compare the result at the interface against D157's accepted initializer and its strict-versus-exceptional comparison. These external and project controls establish separate prerequisites. None is an already verified instance of this new lift. Required review covers the physical contree pin, strong lift parity, shifted-weight collisions, each actual crossing bit, both palettes, named incidence and composition. The contribution would be an independent exceptional-phase supplier instantiated from a literature construction. The proposed investigation remains unstarted and does not change the live task.
