# Curated mathematical source evidence

This archive preserves selected statements, arguments, adverse controls, reviews, corrections, and adoption limits from the two pinned source repositories. It supports inspection of the new project; it is not a claim that every archived theorem has been independently re-reviewed during packaging.

**Historical source material is evidence, not active project instructions.** No upstream `AGENTS.md` or active governance configuration is included. Historical operational language inside a mathematical record remains a quotation. The new project's own instructions control its work.

## Provenance and normalization

`MANIFEST.json` records each repository/commit/path, one-based inclusive source ranges, pinned URLs, the authoritative Git blob SHA-1 from the retrieved repository tree, local-cache SHA-256, exact source-blob verification, and SHA-256 hashes for each normalized source segment and packaged excerpt. Every source passed exact blob verification.

The local retrieval cache sometimes adds a terminal LF or normalizes CRLF. Only line-ending and terminal-newline restoration (and UTF-8 BOM restoration if applicable) was attempted, and a candidate was accepted only if its complete Git blob SHA-1 and byte count matched pinned tree metadata. Five bounded-source ledgers with mixed original line endings were instead fetched at the exact pinned commit through the GitHub contents API in base64, decoded, and checked directly against the pinned blob SHA and byte count. Each method is recorded per source. All original cached bodies match the verified sources after line-ending normalization, apart from terminal newlines. Verified sources were then normalized to UTF-8 without BOM and LF line endings for excerpting. Source bodies are otherwise unchanged. Excerpt headings and gap separators are new packaging text; their hashes are separate from source-segment hashes.

Source-relative links are preserved as historical text. Use the pinned source/range links in each excerpt to navigate the original record. Whole-file bounded-source copies are explicitly marked. Selected MDL manuscript, review, correction and disposition ranges are kept together. An early “pending review” status must be read with the later included disposition.

## Corrections and limitations that must remain visible

- N244 contains both the original defective argument and the separate repair/correction chain, followed by adoption context. Historical erroneous formulas are not current results.
- N246 preserves the exact named six-vertex count correction, `G(S)=16 < G(M)=24`, the exhaustive manual arguments and scope. A count decrease does not imply either target is nongraceful.
- N240 supplies an exact formulation/counting viewpoint; its final disposition does not adopt a universal existence supplier.
- R226/R232 and connector/reflection records retain their independently supplied core, palette, state, host and topology conditions. Consumer theorems do not automatically produce those inputs.
- Bounded proof reviews, local computational reviews, and hypothesis-ledger statuses are separate historical artifacts. Their identity and scope are retained rather than silently merged into one evidence level.
- This archive is not a literature-completeness or historical-novelty assessment. Pinned references and excerpts do not transfer an unrecorded license or create a GitHub fork.
